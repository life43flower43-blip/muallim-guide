## طبيعة المساق
المساق «المهارات» يعلّم المعلم والطالب مهارات عملية قابلة للتطبيق: التفكير الناقد والإبداعي، حل المشكلات، اتخاذ القرار، الفوق معرفية، الدراسة، إدارة الوقت، التواصل، المهارات الاجتماعية والعاطفية، المهارات الرقمية، مهارات القرن الحادي والعشرين، المهارات النفسية حركية، القراءة والكتابة المتقدمة.
- زاوية المحتوى: **مهارات العمل القابلة للممارسة** — لكل مفهوم: تعريف دقيق، ثم آلية التطبيق خطوة بخطوة، ثم موقف صفّي أو جامعي أو منزلي ملموس، ثم قيمة تطبيقية.
- التأصيل علمي صادق: عند الحكم على استراتيجية اذكر مصدرها وموضعها العلمي بصدق (متى نُقدرت ومتى نُقّدت ومتى تفوقت على غيرها).
- المحتوى صالح للمعلم الذي يدرب طلابه وللطالب الذي يطور نفسه — اجعل الشواهد تمزج بين الوجهين دون تعميم صفي ممل.

## ملف الدفعة
- المسار: `/home/z/my-project/scripts/c1_batches/batchNN.py` (حسب رقم دفعتك).
- الترويسة الإلزامية:
```python
# -*- coding: utf-8 -*-
"""الدفعة رقم NN من موجة التوسعة لمساق «المهارات»: فصل «<اسم الفصل>» بعشرة مفاهيم."""
import sys, os
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
sys.path.insert(0, os.path.join(os.path.dirname(os.path.dirname(os.path.abspath(__file__))), "m4_batches"))
import m4_build
m4_build.COURSE_ID = "C1"
from m4_build import C, MCQ, TF

CONCEPTS = [
    # عشرة استدعاءات C فقط — كل مفهوم بعناوينه الحرفية المكلَّف بها وبالترتيب
]

QUESTIONS = [
    # أربعون استدعاءً: أسئلة كل مفهوم متتالية بعده مباشرة بالنمط الرباعي
]
```
- معرف المفهوم داخل دفعتك: `C1BNN` (مثال: `C1B07`) لكل مفاهيم دفعتك وأسئلتها — إعادة الترقيم آلية لاحقًا.
- استدعاء المفهوم: `C("C1BNN", "<اسم الفصل الحرفي كما كُلِّفت>", "<عنوان المفهوم الحرفي>", "الشرح", [شواهد خمسة], "الخلاصة")`.
- **العناوين العشرة إلزامية حرفيًّا كما أعطيتُ إياك وبالترتيب نفسه** — لا تبدّل ولا تعيد صياغة عنوان.

## مواصفات المفهوم
- **الشرح**: ٤-٦ جمل، ≥٣٥٠ حرفًا، صياغة أكاديمية أصيلة بمنهجية «تعريف ثم آلية التطبيق ثم مثال صفّي أو جامعي أو منزلي ثم قيمة تطبيقية». افتتاحية الشرح تعيد العنوان نصًّا لتكتمل جملته (مثل: «العصف الذهني وقواعده الفعالة هو...»).
- **الشواهد**: ٥ مواقف تطبيقية ملموسة بأسماء عربية ومراحل متنوعة (ابتدائي/متوسط/ثانوي/جامعي/منزل)، كل شاهد ≥٦٠ حرفًا، مواقف مختلفة لا تعيد المثال نفسه، وبأسماء معلمين وطلاب متنوعة.
- **الخلاصة** (`example`): جملة موجزة ٣٠-١٣٠ حرفًا تلخص جوهر المفهوم.

## مواصفات الأسئلة (٤ لكل مفهوم بهذا الترتيب حرفيًّا)
1. `MCQ("C1BNN", "سهل", ...)` — سؤال مباشر عن التعريف أو المحور الأساسي.
2. `MCQ("C1BNN", "متوسط", ...)` — تطبيق موقفي أو تمييز بين المفاهيم أو ترتيب خطوات.
3. `TF("C1BNN", "متوسط", ..., True, ...)` — عبارة **صحيحة**.
4. `TF("C1BNN", "صعب", ..., False, ...)` — عبارة **خاطئة** بسوء دقيق قابل للاعتقاد.
- البدائل الخاطئة في الاختيار: ٣ مغالطات شائعة قابلة للاعتقاد بأطوال متقاربة (انحياز طولي ≤١٫٤).
- **التعليل**: ≥١٢٠ حرفًا لكل سؤال، يشرح لماذا الصواب صواب ولماذا كل بديل خاطئ، بأساليب افتتاح متنوعة بلا قالب واحد.
- نصوص الأسئلة فريدة داخل الدفعة، وكل سؤال يختبر وجهًا مختلفًا من المفهوم، ولا تُفصح صواب الإجابة في نص سؤال آخر.

## قواعد لغة حاسمة (رفض تلقائي عند المخالفة)
- **صفر حروف لاتينية** في أي نص، وصفر أرقام لاتينية — الأرقام مشرقية دائمًا: ٠١٢٣٤٥٦٧٨٩.
- الفاصلة العشرية: ٫ (مثل ٠٫٧٠) — علامة المئة: ٪ — التنصيص: «» — لا حروف صينية إطلاقًا.
- يُمنع كلمة «تلميذ» بأشكالها — استخدم «طالب» أو «الطلاب».
- **اختصارات ورموز ممنوعة مع بدائلها**: بدل (SMART) اكتب «أهداف محددة قابلة للقياس»، بدل (SQ3R) اكتب «خطوات القراءة الدراسية الخمس»، بدل (PQ4R) اكتب «خطوات القراءة الدراسية الخمس»، بدل (EQ) اكتب «الذكاء العاطفي»، بدل (IQ) اكتب «معدل الذكاء»، بدل (AI) اكتب «الذكاء الاصطناعي»، بدل (KWL) اكتب «جدول ما أعرف وما أريد معرفته وما تعلمته»، بدل (4Cs) اكتب «المهارات الأربع: التفكير الناقد والإبداع والتواصل والتعاون».
- مصطلحات أجنبية تُعرَّب كتابةً بالعربية: «بومودورو» تُذكر بوصفها «جلسات التركيز المتقطعة»، و«كورنيل» طريقة تدوين مقبولة عربية، و«ميند ماب» تُكتب «الخريطة الذهنية»، و«برينستورمينغ» تُكتب «العصف الذهني».
- أسماء العلماء تُكتب بالعربية: «دي بونو»، «جولفورد»، «تورانس»، «بلوم»، «مارزانو»، «سيجي»، «فلافل»، «إبينغهاوس»، «روبنسون»، «فانسيكو»، «باندورا» (تنتهي بون)، «باوك»، «ديوي»، «بيرنر» — ولا لاتينية إلا كلاتها عربية.

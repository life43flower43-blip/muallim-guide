3. **مصطلحات أجنبية تُثبت قبل الكتابة:** Meta-analysis (التحليل البعدي)، Item analysis (التحليل الفقري)، Self-Determination Theory، Growth/Fixed mindset، Learned helplessness، Connectivism (الاتصالّية)، Rubric، ADDIE، SAM، accommodation (المواءمة) — تُشرح بالعربية مع إبقاء المصطلح.
4. **دمجات داخل الدفعة موثقة:** المرجعي للمحك→للمعيار (58)، المنهج→المنهج الدراسي (104/112)، كفاءة→كفايات المعلم (120)، أنماط→أساليب التعلم (60/119)، الفاعلية الذاتية→الكفاءة الذاتية (105/1)، التجارب→التجربة (65/13).
